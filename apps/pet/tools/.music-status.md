# BGM（Suno）生成诊断报告 — 2026-10-25

结论：**API 不通，未生成任何音频文件**（bgm 目录保持为空）。前端已有 WebAudio 程序化音乐盒兜底，不阻塞。

## 探测结果（key 有效性已确认）

| 尝试 | 端点 / 模型 | 结果 |
|---|---|---|
| 1 | `POST /_open/suno/music/generate`（契约字段 inputType=10 + gptDescriptionPrompt + mv=chirp-v4，带 Accept/UA） | HTTP 200 但 `text/html`（SPA 首页），非 JSON |
| 2 | `GET /_open/suno/music/getState?taskBatchId=probe123` | 同上，HTML |
| 3 | 路径变体 `/open/suno/api/generate`、`/suno/music/generate`、`/_open/suno/generate` | 全部 HTTP 200 HTML（前端路由兜底页） |
| 4 | `GET /v1/models` | HTTP 200 JSON，key 有效；列表含 `suno-v4.5`、`suno-v4.5+`、`suno-v6`（**无 chirp-v3/v4/v4-5/v5**） |
| 5 | `POST /v1/chat/completions` + `chirp-v4` | HTTP 503 `shell_api_error`（模型已下架/无路由） |
| 6 | 同上 + `suno-v4.5` | HTTP 500 `code: "suno_task_failed"`（到达 Suno 后端但任务创建失败） |
| 7 | 同上 + `suno-v6` | HTTP 400 `code: "billing_expression_invalid"`（当前 key 无该模型计费权限） |
| 8 | 同上 + `suno-v4.5+` | HTTP 500 `code: "suno_task_failed"` |

## 诊断

1. `/_open/suno/music/*` 网关专用路径已不存在：网关把未匹配路径回退到 SPA 首页（200 + HTML），skill 契约文档（credit-media-skill，源自 2025 年的 Apifox 文档）已过时。
2. Suno 能力已迁移到 chat-completions 路由，模型名改为 `suno-v4.5(+)` / `suno-v6`：
   - `suno-v6`：key 无计费权限。
   - `suno-v4.5` / `suno-v4.5+`：能路由到 Suno，但 `suno_task_failed`——疑似网关侧 Suno 渠道故障或参数契约变化（chat 消息如何映射 prompt/tags 无文档），客户端侧无法修复。
3. key 本身有效（/v1/models 正常返回）。

## 建议

- 稍后在网关侧修复 Suno 渠道或开通 suno-v6 权限后重试：`node tools/gen-music.mjs`（脚本已就绪，但需把 `mv` 改为 chat 路由模型名或等 `/_open/suno` 路径恢复）。
- 在此之前依赖前端 WebAudio 程序化音乐盒兜底。
